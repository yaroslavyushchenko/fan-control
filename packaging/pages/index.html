fan-control @VERSION@

Manual fan control (auto / full) for the Acer Predator PH315-51 on Linux. Only for that model: the installer refuses to run on other hardware.

curl -fsSL https://yaroslavyushchenko.github.io/fan-control/install.sh | sh

Debian and Ubuntu get the signed APT repository, Arch-based systems the signed pacman repository, so updates arrive with your normal system upgrades.

  • APT: deb [signed-by=/etc/apt/keyrings/fan-control.asc] https://yaroslavyushchenko.github.io/fan-control/apt stable main
  • pacman: [fan-control] with Server = https://yaroslavyushchenko.github.io/fan-control/arch/$arch
  • Signing key: fan-control.asc
